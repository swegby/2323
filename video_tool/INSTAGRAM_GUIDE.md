# 📈 Instagram Reels: за что режут охваты и как набирать просмотры

Собрано из актуальных источников (2025–2026) + как это закрыто в нашем уникализаторе.

---

## 1. К чему придирается Instagram (что реально проверяется)

### 1.1 Originality Score / визуальный фингерпринт
С 2024-го для Reels, а с апреля 2026-го **и для фото/каруселей** Meta считает
«оценку оригинальности». Система сравнивает загрузку с уже существующими
роликами и, если **70 %+ визуала или аудио совпадает** с чужим оригиналом,
показ идёт оригиналу, а копия давится.
Аккаунты-агрегаторы (в основном репосты за скользящие 30 дней) получают
пометку *aggregator* и режущий охват штраф **от 24 часов до 30 дней**
(бьёт по не-подписчикам, подписчики видят как обычно).

### 1.2 Дубликаты внутри своего же аккаунта
Повторная заливка одного и того же файла = спам-сигнал. Инста сравнивает:
- те же кадры/пиксели,
- **тот же хук — первые 6–7 секунд** (сканируется пристальнее всего),
- ту же структуру монтажа (где смена сцены, ритм),
- тот же звук.

Минимальных правок (поменял подпись, обложку, чуть подвинул текст, обрезал
полсекунды) **недостаточно** — это считается тем же видео.

### 1.3 Что конкретно сравнивается технически
| Слой | Что смотрят | Чем ломается |
|---|---|---|
| Пиксели / кадры | perceptual hash кадров, композиция, ключевые кадры | зеркало, зум, сдвиг, поворот, кроп |
| Цвет | гистограмма, яркость/контраст/насыщенность | цветокор, гамма, hue |
| Частоты | DCT-паттерны, шум-профиль | зерно/шум, резкость, ре-энкод |
| Структура | длительности сцен, ритм монтажа, точки склейки | дрожание длительностей, порядок/тайминг |
| Аудио | аудио-фингерпринт (Audible Magic / Rights Manager) | питч+темп, EQ, фоновый шум, замена трека |
| Файл | хеш-сумма, метаданные/EXIF, параметры энкодера | чистка метаданных, новый девайс, CRF/GOP/FPS |

⚠️ Важно про музыку: **изменение скорости/питча НЕ обходит** аудио-фингерпринт
Meta (заявленная точность детекта модифицированных треков ~97 %). Копирайтный
трек всё равно поймают и замутят/заблокируют. Поэтому:
используй Meta Sound Collection, свою озвучку или royalty-free.

### 1.4 Прочие красные флаги
- Водяной знак TikTok/CapCut — прямое понижение (подтверждено Моссери).
- Аудио из TikTok — не лицензировано для Meta, ограниченная раздача.
- Видео, больше чем наполовину закрытое текстом.
- Reels длиннее 3 минут — почти не идут в discovery.
- Одинаковые подписи под всеми роликами, спам-постинг 10 раз в день.

## 2. Как набирать просмотры (что реально двигает охват)

**Топ-сигналы ранжирования Reels 2026:**
1. **Watch time / досмотры** — главный сигнал.
2. **Отправки в Директ (DM sends)** — весят больше лайков для выхода на
   не-подписчиков.
3. **Оригинальность** — низкий originality score обнуляет всё остальное.
4. Комментарии, пересмотры, сохранения.

**Практика:**
- **Хук — первые 1–3 секунды.** Он решает досмотр. Поэтому в нашем софте хук
  берётся из `folder_1` и (по умолчанию) **не уникализируется** — он должен
  остаться идеальным: резкий, ровный, без шума и зеркала.
- **Много вариантов хука, а не много копий одного ролика.** Инста поощряет
  «похожие ролики с вариациями» и наказывает «то же самое второй раз».
  Держи 10–30 разных хуков в `folder_1` — тогда каждая сборка отличается там,
  где алгоритм смотрит внимательнее всего.
- **Длина:** 7–20 сек для максимальной досматриваемости связок, 60–90 сек —
  где выше вовлечение при говорящем контенте. Всё, что >3 мин — в стол.
- **Луп**: собирай так, чтобы конец клеился с началом → пересмотры.
- **Текст-крючок на экране** в первом кадре + вопрос/интрига → комменты и репосты.
- **Подписи под SEO**, а не пачка хештегов: 3–5 ключевых фраз словами, которые
  реально ищут (Instagram ушёл в интересы/поиск, «Your Algorithm»).
- **Ниша консистентно**: аккаунт с одной темой быстрее получает «свою» аудиторию
  в холодном старте.
- **Cold start**: первые 30–60 минут решают. Публикуй, когда твоя аудитория онлайн,
  и не удаляй/не редактируй ролик в это время.
- **Trial Reels** — тест на не-подписчиках, но дубликаты в трайлах теперь тоже
  режут: заливай варианты, а не копии.
- **Не выкладывай один и тот же файл на несколько аккаунтов** — это самый частый
  способ поймать штраф за near-duplicate. Для мультиаккаунта: разные хуки +
  включённый уникализатор.
- **Один аккаунт = 1–3 ролика в день максимум**, иначе спам-сигнал.

## 3. Что уже автоматизировано в приложении

| Слой отпечатка | Функция в «Уник» |
|---|---|
| Геометрия | Зеркало (по % роликов), микро-зум + сдвиг кадра, микро-поворот |
| Цвет | Яркость / контраст / насыщенность / гамма / hue |
| Частоты | Зерно (noise), микро-резкость / софт, виньетка |
| Оверлей | Динамическая сетка/точки с низкой прозрачностью, плавно ползущая по кадру |
| Структура | Дрожание длительностей сегментов ±2–9 %, FPS ±1 |
| Аудио | Питч со сдвигом темпа (длительность сохраняется), громкость, EQ, неслышимый розовый шум |
| Файл | Чистка метаданных + новый «девайс»/дата/UID, CRF ±1, случайный GOP и B-кадры, случайное имя файла |
| Музыка | Секция «Музыка (фон)»: случайный трек на ролик + случайная точка старта — у каждой сборки свой аудио-слой |
| Хук | Галка **«НЕ трогать хук (сегмент 1 / folder_1)»** — включена по умолчанию |
| Текст | Рандомные числа `{rand:…}` и вариации пресетов текста (уже было) |

Плюс к софту, руками: **разные подписи, разные обложки, разные хуки, разный
звук** — именно этих слоёв алгоритму хватает, чтобы считать ролики разными.

## 4. Чек-лист перед массовой заливкой

- [ ] В `folder_1` лежит ≥10 РАЗНЫХ хуков (не один, размноженный уникализатором).
- [ ] «Уник» включён, пресет «Безопасный» (или «Максимум» для холодных аккаунтов).
- [ ] Галка «НЕ трогать хук» стоит, если хук — скринкаст/лицо/читаемый текст.
- [ ] Для статичных сцен/скринкастов включена «Динамическая сетка» — она даёт движение в кадре и разные покадровые хеши.
- [ ] Зеркало **выключено**, если в кадре есть читаемые надписи (они отзеркалятся).
- [ ] Треки лежат в `music/`, включён «Случайный трек» + «Случайная точка старта».
- [ ] Звук: свой/Meta Sound Collection, без TikTok-аудио и водяных знаков.
- [ ] Разные подписи под каждый ролик, 3–5 ключевых фраз.
- [ ] Не больше 1–3 публикаций в день на аккаунт, разные хуки на разных аккаунтах.
